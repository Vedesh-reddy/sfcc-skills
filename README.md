# SFCC Skills for Claude Code

One consolidated skill covering Salesforce B2C Commerce Cloud (SFCC / Demandware): the `b2c` CLI (deploys, sandboxes, jobs, WebDAV, logs, MRT, eCDN, SLAS, Account Manager) and cartridge development (SFRA controllers, ISML, forms, hooks, custom objects, job steps, web services, Custom SCAPI, Page Designer, metadata, localization).

## Install

In Claude Code:

```
/plugin marketplace add YOUR_GITHUB_USERNAME/sfcc-skills
/plugin install sfcc-b2c-commerce@sfcc-skills
```
